# Как работать в репозитории

1. Не пушим напрямую в `main` — это ветка для деплоя.
2. Для каждой задачи создаём ветку от `main`:
   ```bash
   git checkout main && git pull
   git checkout -b feature/короткое-описание
   ```
3. Коммитим небольшими осмысленными шагами.
4. Пушим ветку и открываем Pull Request в `main`:
   ```bash
   git push -u origin feature/короткое-описание
   gh pr create
   ```
5. Ждём, пока пройдёт CI и кто-то из команды посмотрит PR, затем мёржим.

## Именование веток

- `feature/...` — новая функциональность
- `fix/...` — исправление бага
- `docs/...` — документация

## Секреты

Никогда не коммитим ключи, пароли и `.env`. Секреты для деплоя хранятся в
**Settings → Secrets and variables → Actions**.
